# 📊 Sales Performance & Revenue Analytics

An end-to-end sales analytics project using **Python, SQL, Excel, and data visualization** to analyze revenue, profitability, regional performance, product performance, customer activity, and sales trends.

---

## 🎯 Project Objective

The objective of this project is to analyze retail sales data and convert raw transaction data into meaningful business insights.

The analysis focuses on:

- Revenue and profit performance
- Monthly sales trends
- Regional performance
- Category and sub-category profitability
- Product performance
- Customer contribution
- Average Order Value (AOV)
- Profit Margin
- Month-over-Month (MoM) growth
- Discount and profitability analysis
- Loss-making products

---

## 📂 Dataset

**Dataset:** Superstore Sales Dataset

The dataset contains retail transaction-level information covering:

- Orders
- Customers
- Products
- Categories
- Sub-Categories
- Regions
- Sales
- Quantity
- Discounts
- Profit
- Order Dates
- Shipping Dates
